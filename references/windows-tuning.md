# Windows 游戏优化：安全白名单与危险黑名单

原则：**只做安全且完全可逆的设置**。宁可少优化 2 帧，也不做可能让系统不稳定、需要重装才能修复的操作。

---

## 一、安全白名单（可以做）

### 1. Windows 游戏模式（Game Mode）

**检查**：设置 → 游戏 → 游戏模式
**建议**：**开启**

**为什么**：游戏模式会抑制后台的 Windows Update 安装、驱动安装提示，并优先把 CPU 资源分配给前台游戏。对 WoW 这种主线程敏感的游戏，能减少随机卡顿。

**代价**：极小。少数机器上会导致录制功能弹窗，可在同一页面关闭"使用游戏模式录制游戏剪辑"。

**可逆性**：一键开关，完全可逆。

---

### 2. 硬件加速 GPU 调度（HAGS）

**检查**：设置 → 系统 → 显示 → 图形 → 默认图形设置 → "硬件加速 GPU 调度"
**状态**：Win10 2004+ / Win11 默认开启

**建议**：**实测决定，不要预设**

**为什么**：HAGS 把 GPU 调度从 CPU 移到 GPU 上，理论上降低 CPU 开销和延迟。但**实际效果因驱动版本、显卡、游戏而异**——部分组合下反而出现帧时间抖动。

**正确做法**：
1. 记录当前状态（注册表 `HKLM:\SYSTEM\CurrentControlSet\Control\GraphicsDrivers` 的 `HwSchMode`：`2`=开，`1`=关）
2. 保持现状跑一轮基准测试
3. 切换状态，**重启**
4. 再跑一轮
5. 比较 1% Low 与最低帧，选更好的那个

**代价**：需要重启系统。完全可逆。

---

### 3. 电源模式

**检查**：设置 → 系统 → 电源和睡眠 → 其他电源设置；或 `powercfg /getactivescheme`

**建议**：**高性能**，或启用"卓越性能"后再选它

**为什么**：默认的"平衡"模式会让 CPU 在负载判断上保守降频。WoW 团本开怪时 CPU 需求瞬间暴涨，平衡模式来不及升频，**直接表现为开怪瞬间的帧数断崖**。

**代价**：待机功耗略高、风扇转得更积极。笔记本会明显减少续航。

**可逆性**：一条命令切回，完全可逆。

```powershell
# 查看当前
powercfg /getactivescheme
# 切到高性能
powercfg /setactive 8c5e7fda-e8bf-4a96-9a85-a6e23a8c635c
# 切回平衡
powercfg /setactive 381b4222-f694-41f0-9685-ff5bb260df2e
```

> ⚠️ 笔记本用户注意：高性能模式会显著减少续航，插电时使用即可。

---

### 4. 后台高占用程序

**检查**：任务管理器 → 进程 → 按 CPU 排序

**建议**：游戏前关闭以下内容

| 类型 | 例子 | 为什么 |
|---|---|---|
| 浏览器 | Chrome / Edge 开几十个标签 + 硬件加速 | 常驻占用大量 CPU 与显存，是 WoW 掉帧的常见元凶 |
| 云同步 | OneDrive、百度网盘、Dropbox | 同步时占磁盘 IO 与 CPU |
| 直播/录制 | OBS、XSplit | 编码器开销 |
| 其他游戏平台 | Steam、Epic 后台下载 | 下载占磁盘与网络 |
| 杀毒扫描 | 全盘扫描 | 磁盘 IO 打满 |

**代价**：需要养成习惯，无系统风险。

**可逆性**：随时重新打开。

---

### 5. Xbox Game Bar / 后台录制

**检查**：设置 → 游戏 → Xbox Game Bar

**建议**：**关闭后台录制**（Game Bar 本身可保留）

**为什么**：后台录制（"记录刚才发生的事"）会持续占用 GPU 编码器，直接吃掉帧数并造成帧时间抖动。这是"帧数莫名其妙比别人低一截"的常见原因。

**代价**：失去即时回放功能。

**可逆性**：一键开关。

> 注意：即使关闭了 Game Bar，Win11 的"游戏录制"可能仍在。检查 设置 → 游戏 → 捕获 → "记录刚才发生的事" 是否为关。

---

### 6. Discord Overlay

**检查**：Discord → 设置 → 游戏叠加 → "启用游戏内叠加"

**建议**：**团本中关闭**

**为什么**：Discord 叠加层使用 GPU 注入渲染，在 DX12 游戏中可能引入额外开销与帧时间抖动。部分组合下会导致明显卡顿。

**代价**：失去游戏内 Discord 通知与语音面板。可用手机或第二屏代替。

**可逆性**：一键开关。

---

### 7. GeForce Overlay / NVIDIA Overlay

**检查**：GeForce Experience → 设置 → 常规 → "游戏内覆盖"

**建议**：**若不需要即时回放/录制，关闭**

**为什么**：与 Xbox Game Bar 同理，覆盖层是持续运行的 GPU 注入进程。即使不主动使用，也会驻留并占用资源。

**代价**：失去 Alt+Z 快捷录制、即时回放、游戏滤镜。

**可逆性**：一键开关。

---

### 8. 其他安全建议

| 项目 | 建议 | 说明 |
|---|---|---|
| 显示器刷新率 | 设为显示器标称最高值 | **头号"白优化"陷阱**，很多人插了 144Hz 显示器却一直跑 60Hz |
| 浏览器硬件加速 | 不玩游戏时无所谓，游戏前关掉浏览器 | 释放显存 |
| 游戏装在 SSD | 强烈建议 | 机械硬盘会导致贴图弹出与加载卡顿 |
| 关闭不必要的开机启动项 | 任务管理器 → 启动 | 减少常驻后台占用 |

## 二、危险黑名单（绝对不做）

以下操作**一律拒绝执行**。它们要么风险远大于收益，要么是流传已久的伪优化。

| ❌ 禁止操作 | 为什么禁止 |
|---|---|
| **删除/禁用系统服务** | 可能导致系统功能损坏、无法更新、无法恢复。收益几乎为零。 |
| **关闭 Windows Defender / 安全中心** | 显著增加安全风险。Defender 的实时监控在现代系统上开销极低。 |
| **修改未知注册表参数** | 网上流传的"优化注册表"多半是针对旧版本 Windows，在现代系统上无效甚至有害。 |
| **所谓"网络延迟神级注册表优化"** | 典型伪科学。TCP 参数调整对游戏延迟几乎无影响，改错反而导致网络异常。 |
| **禁用 Windows Update 服务** | 系统失去安全更新，且后续更新可能失败。 |
| **修改 HPET / BCD 等启动参数** | 高风险：改错会导致**系统无法启动**。对帧数的影响在现代系统上未经证实。 |
| **禁用 Core Parking / 改处理器调度注册表** | 现代 Windows 的调度器已足够智能，手动干预通常无效。 |
| **使用来路不明的"一键优化"工具** | 无法审计其具体行为，可能同时做了上述多种危险操作。 |
| **删除系统文件 / 精简系统组件** | 不可逆，风险极高。 |
| **刷非官方 BIOS / VBIOS** | 硬件损坏风险。 |
| **强制关闭关键进程（explorer、dwm 等）** | 系统不可用。 |

---

## 三、执行原则

1. **一次只改一项**（或一组明确相关的项），改完实测，确认有效再继续。
2. **每一项修改前记录原值**，写进 `system-state.json`。
3. **任何用户要求执行黑名单操作时，明确拒绝并解释原因**，不要为了"满足用户"而执行。
4. 若某项优化的收益测不出来（1% Low 无改善），**建议改回原状**，保持系统简洁。
