# RTX 4060 Ti 专项调校

## 一、这张卡的性格

| 特性 | 数值 / 表现 | 对 WoW 的含义 |
|---|---|---|
| 架构 | Ada Lovelace (AD106) | 支持 DX12、光追、DLSS |
| 显存 | 8GB / 16GB GDDR6，128-bit | **128-bit 窄总线是短板**：高分辨率 + 高贴图 + 多后台时容易顶到带宽/容量上限 |
| 算力定位 | 1080p 高刷主力、1440p 中高画质 | WoW 在 1080p/1440p 下，**大多数场景不是 GPU 算力瓶颈** |
| 光追单元 | 有，但规模有限 | WoW 光追阴影代价远大于收益，**直接关** |
| 功耗 | 约 160W | 温度通常不是问题，但仍要记录 |

**核心结论**：RTX 4060 Ti 跑 WoW，**瓶颈经常在 CPU 主线程和插件，而不是这张显卡本身**。所以调校思路是——

> **把 GPU 侧"性价比低"的负载砍掉（阴影、光追、SSAO、远景、地面杂物），把 GPU 侧"性价比高"的画质守住（贴图分辨率、各向异性过滤、投影贴图），然后把精力转向 CPU 侧（Spell Density、粒子、插件）。**

---

## 二、优先减少的（砍这些）

| 项目 | 为什么在 4060 Ti 上要砍 | 推荐值 |
|---|---|---|
| **阴影 Shadow Quality** | 阴影分辨率对 128-bit 显存带宽非常敏感；WoW 阴影观感收益极低 | 团本 Low，日常 Medium |
| **光线追踪阴影 Ray Traced Shadows** | 4060 Ti 的 RT 单元跑 WoW 光追阴影代价巨大，画面几乎看不出差别 | **关闭（无条件）** |
| **SSAO** | 每帧深度采样，纯 GPU 开销，团本战斗中完全看不出 | 关闭或 Low |
| **粒子 Particle Density** | 团本 AOE 高峰期的主要负载尖峰 | 团本降低一档 |
| **远景 View Distance** | 顶点与绘制调用双消耗，战斗无信息价值 | 5–7 |
| **环境细节 Environment Detail** | 同上 | 5–7 |
| **地面杂物 Ground Clutter** | 海量小物件绘制调用，同时打 CPU 和 GPU | 4–6 |

---

## 三、尽量保持的（守这些）

| 项目 | 为什么在 4060 Ti 上要守 | 推荐值 |
|---|---|---|
| **Texture Resolution 贴图分辨率** | 主要吃显存容量而非算力。8GB 在 1080p/1440p 跑 WoW 绰绰有余。<br>**降贴图会让地面 AOE 圈、技能图标、地形边界发糊，直接影响走位判断** | **High（最高）** |
| **Texture Filtering 各向异性过滤** | Ada 架构上 8x/16x 开销极低，斜视角地面清晰度收益明显 | **8x 或 16x** |
| **Projected Textures 投影贴图** | 奉献、暴风雪、各类 AOE 警示圈依赖它。关掉后脚下圈极淡，**是实战中最不该省的东西** | **开启** |
| **必要的战斗特效可读性** | Spell Density 降到 Essential 会减少"他人法术视觉"，但自身技能与关键预警仍在。<br>**不要用关闭 Projected Textures 或降贴图的方式换帧** | 保持 |

## 四、显存（VRAM）管理

128-bit / 8GB 是这套配置最需要注意的地方：

**会大量占用显存的行为**
- 4K 分辨率
- 高贴图 + 大量插件材质包
- 浏览器（Chrome/Edge）开硬件加速且开着几十个标签
- 后台开着视频播放器、直播软件、OBS
- 多显示器 + 高刷

**显存接近上限的症状**
- 帧数不是缓慢下降，而是**骤降**
- 同时出现明显卡顿、贴图弹出（远处物体突然变清晰）
- GPU 占用率反而下降（在等显存换页）

**对策（按顺序）**
1. 关掉后台浏览器硬件加速 / 关掉不用的浏览器窗口
2. 降低 Max Background FPS
3. 减少插件材质包
4. **最后**才考虑把 Texture Resolution 降一档

> 基准测试时必须记录 `GPU VRAM used`。若长期低于总容量的 80%，**完全不需要动贴图**。

## 五、按分辨率的推荐起点

| 分辨率 | Render Scale | 贴图 | 预期定位 |
|---|---|---|---|
| 1920×1080 | 100% | High | GPU 基本无压力，瓶颈几乎必然在 CPU / 插件 |
| 2560×1440 | 100% | High | 平衡点；若 GPU 占用 >95% 可考虑 Render Scale 95% |
| 3440×1440 带鱼屏 | 100% | High | 像素量增加约 34%，阴影和 SSAO 必须压低 |
| 3840×2160 (4K) | 90–100% | High→Medium | **4060 Ti 跑 4K WoW 偏吃力**，建议 Render Scale 90% 并砍阴影/SSAO |

---

## 六、不要做的事

- ❌ 不要为了提帧预防性降低贴图分辨率——这张卡的显存放在 1080p/1440p 下够用，降贴图会付出实打实的画面代价却换不来多少帧。
- ❌ 不要开光追阴影"试试看"——代价大、收益近乎为零。
- ❌ 不要因为"显卡是 4060 Ti 应该很强"就忽视 CPU / 插件排查。团本掉帧十有八九不在 GPU。
- ❌ 不要盲目锁 60 帧"求稳定"——如果显示器是 144Hz，锁 60 是白白浪费刷新率。
